# 🚀 Launch Guide // Deploying Your Profile to GitHub

Your high-tech GitHub profile is fully assembled and optimized! Follow these simple steps to activate it on your GitHub account (`https://github.com/GR8ANSH`).

---

### Step 1: Create the Special Repository on GitHub
1. Open your browser and go to: [https://github.com/new](https://github.com/new)
2. In the **Repository name** field, type: **`GR8ANSH`**
   > 💡 *GitHub will show a green banner: "You found a secret! `GR8ANSH/GR8ANSH` is a special repository that you can use to add a `README.md` to your GitHub profile."*
3. Make sure it is set to **Public**.
4. Leave "Add a README file", ".gitignore", and "License" **UNCHECKED** (we already have everything prepared).
5. Click **Create repository**.

---

### Step 2: Push Your Code via Terminal
Open your terminal (PowerShell or Bash) in this project folder (`C:\Users\great\.gemini\antigravity\scratch\GR8ANSH`) and run:

```bash
git init
git add .
git commit -m "feat: initialize super hitech profile & snake automation"
git branch -M main
git remote add origin https://github.com/GR8ANSH/GR8ANSH.git
git push -u origin main
```

---

### Step 3: Enable GitHub Actions Permissions (For Animated Snake)
To allow the automated GitHub Contribution Snake to generate and push to your `output` branch:
1. In your `GR8ANSH/GR8ANSH` repository, go to **Settings** > **Actions** > **General**.
2. Scroll down to **Workflow permissions**.
3. Select **"Read and write permissions"**.
4. Click **Save**.
5. Go to the **Actions** tab > Click **"Generate Contribution Grid Snake"** > Click **"Run workflow"** to generate your first snake immediately!
